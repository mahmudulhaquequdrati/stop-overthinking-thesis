# Stop Overthinking, Keep Passing the Tests

**Shortest-Correct LoRA Fine-Tuning versus the Thinking Switch in a Small Code Model (Gemma-4-E4B)**

A thesis built by a beginner, step by step.
We teach a small 2026 AI model (Gemma-4-E4B) to think shorter on code problems,
without getting more answers wrong. Then we check if that is better than simply
switching its thinking OFF. Everything runs for $0 on free Colab and Kaggle GPUs.
